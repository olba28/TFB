## Directory Purposes

**`.planning/codebase/`:**
- Purpose: GSD codebase analysis documents generated by `/gsd-map-codebase`
- Contains: ARCHITECTURE.md, STRUCTURE.md, STACK.md, INTEGRATIONS.md, CONVENTIONS.md, TESTING.md, CONCERNS.md
- Key files: `ARCHITECTURE.md` (system design), `STRUCTURE.md` (this file), `STACK.md` (tech deps)

**`data/`:**
- Purpose: Store downloaded datasets and trained models
- Contains: Subdirectories per data source (one per API fetch), manifest files, .csv/.json files
- Key files: `data/[dataset-id]/manifest.json` (reproducibility metadata)
- Status: Raw data files (.csv, .json) are **NOT version-controlled** (gitignored); only manifests are committed
- Regeneration: Re-run `src/ingesta/fetch_data.py` to rebuild

**`figuras/`:**
- Purpose: Static output figures for thesis appendices
- Contains: PNG, PDF exports from notebooks or Streamlit
- Organization: Subdirectories by thesis chapter or analysis section
- Status: Committed to Git (human-readable outputs)

**`notebook/`:**
- Purpose: Jupyter notebooks for exploratory analysis, prototyping, and one-off analyses
- Contains: .ipynb files, one per major analysis phase
- Naming: `NN-descriptive-name.ipynb` (e.g., `01-eda.ipynb`, `02-modelos-panel.ipynb`)
- Status: Committed to Git; ideal for thesis documentation (shows work, reasoning, figures)
- Future: Extract reusable functions to `src/` modules; use notebooks for orchestration only

**`src/`:**
- Purpose: Modular, reusable Python source code
- Contains: Organized subpackages for ingestion, ETL, modeling, visualization
- Status: Most subdirectories are currently **empty skeletons** (to be implemented)
- Target structure: Transform notebook prototypes → testable functions/modules in `src/`

**`src/ingesta/`:**
- Purpose: Data ingestion — fetch from UN ODS API, validate, create manifest
- Planned contents: `client.py` (API logic), `manifest.py` (versioning), `fetch_data.py` (orchestration)
- Execution: `python src/ingesta/fetch_data.py` or triggered by CI scheduler
- Output: `data/[dataset-id]/manifest.json` + raw files in `.gitignore`

**`src/etl/`:**
- Purpose: Extract, transform, load — clean and merge data into analysis-ready format
- Planned contents: `clean.py` (outlier removal, null handling), `merge.py` (join multi-source data)
- Called by: Notebooks and `src/modelos/` pipeline

**`src/modelos/`:**
- Purpose: Build statistical (econometric) and ML models
- Planned contents: `panel_regression.py` (statsmodels/linearmodels), `ml_models.py` (scikit-learn)
- Outputs: Serialized models to `data/modelos/*.pkl`
- Testing: Unit tests in `src/tests/test_modelos.py`

**`src/dashboard/`:**
- Purpose: Interactive geospatial visualization via Streamlit
- Planned contents: `app.py` (entry point), `plots.py` (Plotly choropleth & time-series)
- Execution: `streamlit run src/dashboard/app.py`
- Dependencies: plotly, streamlit (no GDAL/GeoPandas for Windows compatibility)

**`src/tests/`:**
- Purpose: Unit and integration tests for reproducibility validation
- Planned contents: Test data pipelines, model reproducibility, visualization rendering
- Execution: `pytest src/tests/`

## Naming Conventions

**Files:**

- **Notebooks:** `NN-descriptive-name.ipynb`
  - Example: `01-eda.ipynb`, `02-modelos-panel.ipynb`, `04-interpretability.ipynb`
  - Pattern: Two-digit prefix for ordering, kebab-case description

- **Python modules:** `snake_case.py`
  - Example: `fetch_data.py`, `panel_regression.py`, `interpret.py`

- **Data manifests:** `manifest.json`
  - Location: `data/[dataset-id]/manifest.json`
  - Content: JSON object with keys: `source`, `download_date`, `api_version`, `row_count`, `checksum`, `notes`

- **Serialized models:** `{model_name}_{timestamp}.pkl` or `*.joblib`
  - Example: `panel_ols_2026_07_10.pkl`, `random_forest_v2.joblib`
  - Location: `data/modelos/`

- **Output figures:** `{section}_{figure_number}.png` or `.pdf`
  - Example: `03_04_panel_diagnostics.png` (Chapter 3, Figure 4)
  - Location: `figuras/` or `figuras/[chapter]/`

**Directories:**

- **Data source dirs:** `data/{dataset_id}/` where `dataset_id` = descriptive slug
  - Example: `data/water-stress-un-ods/`, `data/gdp-economic-indicators/`

- **Python packages:** All lowercase, underscore-separated
  - Example: `src/ingesta/`, `src/etl/`, `src/modelos/`, `src/dashboard/`

- **Thesis sections in figuras:** `figuras/{chapter}/` or `figuras/{topic}/`
  - Example: `figuras/03-analisis-estadistico/`, `figuras/04-modelos-ml/`

## Where to Add New Code

**New Data Source (API Ingestion):**
- Implementation: Add new function to `src/ingesta/client.py` (planned) for new API endpoint
- Manifest: `data/[new-dataset-id]/manifest.json`
- Tests: `src/tests/test_ingesta.py`
- Example: To ingest climate data: create `fetch_climate_data()` in `src/ingesta/client.py`

**New Exploratory Analysis:**
- Implementation: New Jupyter notebook in `notebook/` with numeric prefix (e.g., `06-spatial-analysis.ipynb`)
- Follow existing naming: `NN-topic.ipynb`
- Output figures: Export to `figuras/`

**New Statistical Model:**
- Implementation: `src/modelos/panel_regression.py` (if fixed-effects regression) or new file for specialized models
- Tests: `src/tests/test_modelos.py` (test reproducibility, coefficient stability)
- Serialization: Save to `data/modelos/{model_name}_{version}.pkl`

**New ML Model:**
- Implementation: `src/modelos/ml_models.py` (or new file for specialized models, e.g., `time_series.py`)
- Tests: `src/tests/test_modelos.py` (test cross-validation, feature importance)
- Example: Time-series forecasting → new `src/modelos/time_series.py`

**New Visualization / Dashboard Component:**
- Implementation: `src/dashboard/plots.py` (reusable Plotly functions) or `src/dashboard/app.py` (Streamlit layout)
- Static outputs: Export to `figuras/`
- Tests: `src/tests/` (test plot rendering, data input validation)

**Utilities & Helpers:**
- Shared helper functions: `src/utils.py`
- Configuration: `src/config.py` (thresholds, paths, model hyperparameters)
- Example: `src/utils.py` could contain `load_manifest()`, `validate_panel_structure()`

**Tests (New Unit / Integration Tests):**
- Implementation: `src/tests/test_{module}.py` where `module` is the target (e.g., `test_etl.py`)
- Fixtures: `src/tests/fixtures/` for test data
- Execution: `pytest src/tests/`

## Special Directories

**`data/`:**
- Purpose: Runtime data storage (not part of source code)
- Generated: Yes (by `src/ingesta/fetch_data.py` and `src/modelos/` training scripts)
- Committed: Manifests only (.json); raw data and models excluded via `.gitignore`
- Regeneration: Run `src/ingesta/fetch_data.py` to rebuild; retrain models via `src/modelos/` scripts

**`.planning/codebase/`:**
- Purpose: GSD codebase analysis documents
- Generated: Yes (by `/gsd-map-codebase` orchestrator)
- Committed: Yes (analysis snapshots)
- Contents: ARCHITECTURE.md, STRUCTURE.md, STACK.md, INTEGRATIONS.md, CONVENTIONS.md, TESTING.md, CONCERNS.md

**`notebook/.ipynb_checkpoints/`:**
- Purpose: Jupyter checkpoint cache
- Generated: Yes (by Jupyter)
- Committed: No (gitignored)
- Safe to delete: Yes (notebooks re-checkpoint on open)

**`data/modelos/`:**
- Purpose: Trained model serialization
- Generated: Yes (by `src/modelos/` training scripts)
- Committed: No (gitignored; regenerable from source)
- Regeneration: Re-run training scripts in `src/modelos/`
