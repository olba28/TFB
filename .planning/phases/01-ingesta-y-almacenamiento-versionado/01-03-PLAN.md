<objective>
Build the reusable country-classification module (`src/ingesta/countries.py`, per D-15) that produces the canonical M49 country list, the M49→ISO3 crosswalk, and the documented exclusion log — the mechanism that keeps regional aggregates out of the panel (Success Criteria #2, INGEST-03).

Purpose: The UN SDG API's `Indicator/Data` endpoint returns only `geoAreaCode` (M49 numeric), never ISO3, and mixes countries with aggregates ("World", "Sub-Saharan Africa", "High income"). Two UN-native sources close the gap per D-13: `GeoArea/Tree`'s `type` field distinguishes Country leaves from Region aggregates, and the official M49 CSV supplies the ISO3 crosswalk. Phase 2 reuses this module unchanged.
Output: `countries.py`, the versioned M49 reference CSV with documented provenance, and unit tests over a synthetic tree fixture.
</objective>
