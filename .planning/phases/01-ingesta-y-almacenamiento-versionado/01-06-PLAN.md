<objective>
Close the single verified gap from 01-VERIFICATION.md: Success Criterion #3 / INGEST-04 ("copia local versionada del JSON crudo + manifiesto de procedencia"). The 5 on-disk raw JSON files are empty stubs (`{"data": []}`) whose sha256 no longer matches their own manifest sidecars, because `tests/ingesta/test_fetch_data.py::test_run_ingestion_force_true_refetches_even_when_manifest_exists` calls the real `run_ingestion(force=True)` without sandboxing `manifest.RAW_DATA_ROOT`, so `run_ingestion`'s un-mocked `raw_path.write_text()` overwrites the live raw files every time the documented test command runs.

Purpose: Make the versioned raw-JSON artifact durable and trustworthy (checksum-consistent with its manifest) and prevent this class of test-pollution bug from ever recurring silently.
Output: (1) the offending test isolated to a tmp_path sandbox, (2) an autouse regression guard forbidding writes to the real data/raw/ tree during the ingesta test session, (3) restored, checksum-consistent raw JSON files + manifests for all 5 indicators.

This plan does NOT touch the 5 already-verified plans (01-01..01-05) or their scope. It adds one standalone fix plan. Requirements coverage for the phase is already satisfied by those plans; this plan claims only INGEST-04.
</objective>
