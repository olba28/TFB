<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UN SDG API → client.py | Untrusted external JSON crosses into the pipeline; response shape and values are not guaranteed |
| API response content → filesystem paths | File paths must never be derived from response content |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-DoS | Denial of Service | client.py pagination/retry loops | high | mitigate | Retry(total=3) caps retries (D-01); pagination terminates on totalPages/totalElements read per indicator, never an unconditional while-True (RESEARCH Security Domain, DoS row) |
| T-01-PT | Tampering | manifest.py / client.py file+URL construction | medium | mitigate | Paths and URLs built only from the fixed indicator-code list + date.today(); never from response content (Security V5, path-traversal row) |
| T-01-IV | Tampering | client.py response handling | low | mitigate | Validate response has expected pagination keys before indexing; no bare trust of `200 OK` as correctness (RESEARCH anti-pattern) |
</threat_model>
