## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-DIM | Tampering | Global dimension filter zeroing 3/5 indicators | high | mitigate | Per-indicator HEADLINE_DIMENSIONS table + `assert len(filtered)>0` per indicator (Pitfall 1) |
| T-01-VAL | Tampering | "NaN"-string value crashing/corrupting ingestion | medium | mitigate | pd.to_numeric(errors='coerce') for all value parsing (Pitfall 5); store as NULL, do not drop |
| T-01-PT3 | Tampering | fetch_data.py path construction | medium | mitigate | Paths built only from fixed indicator-code constant + date.today(), never from API response content (Security V5) |
| T-01-DoS2 | Denial of Service | Live run pagination over ~50k+ rows | medium | mitigate | Pagination bounded by totalPages per indicator (client.py); Retry(total=3) caps retries; row-count sanity checks in Task 2 |
</threat_model>
