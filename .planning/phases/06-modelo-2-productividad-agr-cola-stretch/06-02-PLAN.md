<objective>
Build `src/model2_agri.py`, a runnable pipeline module that extends the entire Model 1 methodology to the agricultural-productivity indicator (2.3.1) by invoking the shared, unmodified Phase 3/4 modules (`panel_base`, `simulate`, `interpret`) with `dep_var="2.3.1"`, and that serializes its fitted artifacts plus a dedicated Model 2 coverage/exclusions table.

Purpose: MODEL2-01 requires Model 2 to reuse `panel_base.py` with the same specification, SEs, and diagnostics as Model 1 — no re-implementation. MODEL2-02 requires the reduced country coverage (39 vs. 171) to be documented in a dedicated table. MODEL2-03 requires simulation and SHAP to be extended to Model 2. This module delivers all three by parametric reuse (every call is an existing function with different arguments).

Output: `src/model2_agri.py` (pipeline functions + a `_main()` runnable via `python -m src.model2_agri`), `tests/test_model2_agri.py`, and the produced artifacts: `data/modelos/model2_agri.pkl`, `data/modelos/rf_shap_model_m2.pkl`, and the `model2_coverage` table in `data/panel.db`.
</objective>
