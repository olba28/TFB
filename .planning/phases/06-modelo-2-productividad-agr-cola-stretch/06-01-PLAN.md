<objective>
Add a second, explicit coverage-threshold helper `filter_by_min_years` to `src/panel_base.py` so Model 2 (indicator 2.3.1) can be filtered by "≥ N observed years per country" instead of the Model 1 "70%-of-years" rule that leaves the 2.3.1 panel at zero countries (D-01).

Purpose: Model 1's `filter_by_exclusions` reads the fixed 70%-coverage `panel_exclusions` table; the 2.3.1 indicator is reported in ~3-year waves so its max real coverage is 26% and no country survives 70%. D-02 mandates a NEW sibling function computed directly on `panel_clean`, coexisting with `filter_by_exclusions` (never wrapping it), so `panel_base.py` stays the single reusable source of filtering logic with two explicit criteria.

Output: `filter_by_min_years` in `src/panel_base.py` + unit tests in `tests/test_panel_base.py`.
</objective>
