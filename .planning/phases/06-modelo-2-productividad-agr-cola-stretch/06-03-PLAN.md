## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Sidebar widget input -> server-side dict lookup | `st.sidebar.selectbox`'s value is user-controlled (via clicking a fixed dropdown, not free text), then used as a dict key into `models.ACTIVE_MODELS`. Streamlit's `st.selectbox` constrains input to the supplied `options` list, so the resulting value can only ever be one of the two known registry keys -- no arbitrary key/path is reachable through this widget. |
| cached_bootstrap/cached_shap active_model_name param -> pkl path lookup | The new `active_model_name` parameter is always populated from the same constrained selectbox value (never free text), then used only to index the fixed `models.ACTIVE_MODELS` dict for a `pkl_path`. `load_model` still only opens local, project-produced paths already declared in the registry (T-5-02 precedent, unchanged). |
| Local pickle deserialization (data/modelos/model2_agri.pkl, rf_shap_model_m2.pkl) | Same trust posture as Model 1's existing artifacts -- self-produced local files, never network/upload sourced. |
