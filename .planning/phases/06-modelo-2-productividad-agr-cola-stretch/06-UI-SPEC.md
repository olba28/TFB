# Phase 6 — UI Design Contract

> Visual and interaction contract for the Phase 6 dashboard extension (Modelo 2 — Productividad Agrícola). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Context note — this is a pure-reuse/extension phase, not a new UI surface.** Phase 5 already shipped the dashboard's entire design system (Streamlit native theme, Plotly figure conventions, spacing/typography/color scales) in `.streamlit/config.toml` and `06-CONTEXT.md`'s canonical reference `05-UI-SPEC.md`. Phase 6 (D-07, D-08) adds exactly ONE new interactive control (a sidebar model selector) and ONE new recurring copy element (a reduced-coverage caption) — it does not restructure, retheme, or re-derive any existing token. Every table below marked "carried forward unchanged" is copied verbatim from `05-UI-SPEC.md` for the checker's convenience; only the **Phase 6 Additions** subsections under Component Inventory and Copywriting Contract are new contract surface for this phase.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — pure Python/Streamlit project, no npm/React toolchain, shadcn not applicable (unchanged from Phase 5; still no `components.json`/`package.json`/`tailwind.config.*` in repo) |
| Component library | Streamlit native widgets only (`st.tabs`, `st.columns`, `st.selectbox`, `st.sidebar.selectbox`, `st.dataframe`, `st.metric`, `st.container`) + Plotly Express for charts. No custom React/HTML components. |
| Icon library | none — do not use emoji or icon shorthand in tab labels, headers, or the new sidebar selector label (keeps the formal academic tone Phase 5 established) |
| Font | Streamlit's default theme font (Source Sans / system sans-serif fallback), unchanged. No custom `@font-face` or font injection. |

**Theme mechanism:** `.streamlit/config.toml` `[theme]` block, already in place from Phase 5 — Phase 6 does not modify it.

### Phase 6 Additions (D-07, D-08)

| Component | Usage |
|-----------|-------|
| `st.sidebar.selectbox("Modelo activo", ..., key="active_model_name")` | **New.** The single entry point for switching between Modelo 1 and Modelo 2 (D-07). Never rendered when Modelo 1 is active. |

## Color

Carried forward unchanged from Phase 5 — Phase 6 introduces no new color, and the reduced-coverage caption deliberately uses the SAME neutral caption styling as every other `st.caption` in the app (not a warning-yellow or destructive-red), matching D-08's "visible but calm" framing — this is disclosure, not an error state:

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` | Main app background |
| Secondary (30%) | `#EFF3F7` | Sidebar background (now also the visual home of the new model selector), `st.container(border=True)` fill, `st.metric` card background |
| Accent (10%) | `#1B6CA8` | Reserved for: `primaryColor` (now also the sidebar selectbox's focus/selection ring — no new reservation needed, it is the same selectbox mechanism Phase 5 already covers), the fitted/reference line, the simulation `st.metric` central estimate |
| Destructive | not applicable | No destructive actions in Phase 6 either — read-only model switch, no delete/overwrite |

**Explicit non-color decision:** the reduced-coverage caption (D-08) is NOT styled via `st.warning` (which Streamlit renders with a yellow/orange background) — it uses plain `st.caption`, identical treatment to `NO_DATA_CAPTION`. Rationale: a smaller-but-valid, well-documented sample is a disclosed methodological fact for the tribunal (MODEL2-02), not an application warning state; using `st.warning` would visually conflate "something is wrong" with "this model has a different, smaller, honestly-reported N."

Choropleth `Viridis` scale, `.streamlit/config.toml` values, and the SHAP-palette exception are all unchanged from Phase 5.
