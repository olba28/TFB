<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser (localhost)→Streamlit process | Single local user; widget inputs are closed-choice (selectbox), never free text. |
| Streamlit process↔UN SDG API | MUST NOT exist at runtime — enforced by the static no-live-API test (DASH-01). |
| Streamlit process↔network exposure | Default localhost binding only; never `server.address=0.0.0.0`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-5-05 | Spoofing / Information Disclosure (accidental live API call) | `src/dashboard/*.py` at render time | high | mitigate | `test_no_live_api.py` statically asserts no API-client/HTTP import nor the UN SDG host appears anywhere in `src/dashboard/`; all data flows through `data.py` local loaders (DASH-01). |
| T-5-01 | Tampering (input validation) | Mapa-tab selectbox values | medium | mitigate | Selector options come from a fixed whitelist (`INDICATOR_LABELS` + registry); the chosen value is used only as a pandas column key, never interpolated into SQL (V5 closed-choice widgets). |
| T-5-02 | Tampering (untrusted pickle) | Modelo 1 / SHAP tabs `load_model` | medium | mitigate | Only project-produced `.pkl` loaded; no `st.file_uploader` introduced. |
| T-5-03 | Elevation of Privilege (network exposure) | `streamlit run` invocation | low | mitigate | Documented run command uses the default localhost binding; no `server.address` override in `.streamlit/config.toml` (05-01) or in code. |
| T-5-SC | Supply Chain | package installs | low | accept | No new dependency; `AppTest` ships inside the already-pinned streamlit. |
</threat_model>
